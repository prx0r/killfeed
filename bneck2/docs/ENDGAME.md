# Endgame — where this process goes if it keeps working

## The flywheel (already turning)

```
live streams → verdicts → receipts → variables → screens
     ↑                                           ↓
cron resolves predictions ← paper portfolio ← triaged hypotheses
```

Every pass does four things nothing else in the stack does: (1) appends
dated evidence, (2) retires dead possibilities permanently, (3) matures
forward windows, (4) resolves preregistered predictions. Time is the
active ingredient — the system gets smarter by running, not by rewriting.

## What compounds (the actual assets)

1. **The receipt log** — an audited history of what was believed, tested,
   and retired, with hashes. In 90 days this is a backtestable track
   record; in a year it's institutional memory no competitor can buy.
2. **The dead list** — refuted hypotheses + dead variables, kept forever.
   Not searching twice is a compounding advantage (most shops re-learn
   the same lessons quarterly).
3. **Calibrated clocks** — dB/dt, baselines, panel forwards, temporal
   hit-rates per family. These turn today's directional mush into
   tomorrow's position sizing.
4. **The variable registry** — the possibility space itself, terraformed.
   Whoever owns the best-measured scarcity variables owns the game this
   thesis describes (irreducibility applies to us too: our interaction
   history with reality is the moat).

## Steady state (12 months, if run daily)

- Morning: cron pass ran overnight; report waiting with new verdicts,
  retired hypotheses, resolved predictions, updated hit-rates.
- Weekly: reflect memo redirects the bandit arms; dead variables stay dead.
- Monthly: paper portfolio rebalanced on triaged signals vs baselines.
- Quarterly: temporal validation resolves the big preregs (E007-style
  panels mature; acquisition chains re-tested on new deals).
- The agent's job shifts from building instruments to proposing variables
  and attacking mechanisms — the loop handles the rest.

## What winning looks like

Not "an AI that picks stocks." Three things, in order:
1. **A scarcity radar nobody else has**: dB/dt on 16+ nodes, cross-world X
   on incumbents, consistency-arbitrage rows, whale + venue triangulation —
   all timestamped and calibrated. Sellable as intelligence before it ever
   trades a dollar.
2. **A validated discovery engine**: support rate with tight Wilson bounds,
   temporal hit-rates by family, rediscovery checks passing. This is the
   ML-lab plan executed — the step before any ML pipeline, done right.
3. **Capital deployment with receipts**: paper → small → scaled, each step
   gated on the ledger, every position traceable to a hypothesis receipt.
   The fund that can show its work.

## What kills it (watch these)

- **Stopped clock**: cron dies quietly, history stops compounding. Monitor
  the log's heartbeat, not just the code.
- **Threshold rot**: absolute gates set today drift out of meaning as
  regimes change. Baselines/self-calibration are the defense — keep
  extending them (cadence → venues → volatility regimes).
- **Narrative capture**: the lab starts confirming the thesis instead of
  attacking it. Defense: the Critic role, mandatory falsifiers, E005-style
  refutes celebrated, dead list honored.
- **Complexity collapse**: 20 collectors become 60, nobody knows what feeds
  what. Defense: RESOURCES-CANONICAL stays current; one-table formulas;
  stdlib-only discipline (every dep is a future outage).
- **Premature capital**: trading before temporal validation matures turns
  the lab into a P&L hostage. The gates say when — listen to them.

## The deepest endgame

If intelligence commoditizes cognition, the scarce asset is privileged,
proven interaction with reality. This system IS that interaction,
formalized: every receipt is a timestamped collision between a model of
the world and the world itself. Run it for years and it becomes what the
thesis says to own — not a model, not data, but a calibrated,
compounding record of being right and wrong about what becomes scarce.
That record is the product. Everything else — screens, signals, positions —
is exhaust.
