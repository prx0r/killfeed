## Read it

- **30s: LITE, AAOI** — every row lit. LITE's survival = merchant laser market staying tight (B1); AAOI's = avoiding BOM marginalization (B4) + margin (B8). These are binary outcomes, hence option-like payoffs both ways.
- **27: COHR** — single-variable thesis: does telemetry become mandatory (B2=5)? Yes → rerate down to assembler multiple. No → volume story intact.
- **25: MRVL** — a clock: each quarter without bundled PIC+DSP wins = relief; first win = thesis break (B3).
- **19: NVDA** — neither safe nor exposed: needs capex durability (B7) + memory leverage (B6, HBM pricing). AI-chip threat (B5=3) is the only moat question.
- **12s: PANW/CRWD** — pure margin+multiple stories, no physical bottleneck. Boring longs, rich price.
- **CHGG scored 8** because it's posthumous: B9=5 with everything else 0 is what death looks like. Any name migrating toward that shape (B9 rising while other scores collapse) is the next Chegg.
