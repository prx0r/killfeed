# Event taxonomy

Use event types rather than a generic news blob:

- `FRONTIER_CAPABILITY_PROOF`
- `INDEPENDENT_BENCHMARK`
- `MODEL_RELEASE`
- `ARCHITECTURE_CHANGE`
- `CUSTOM_SILICON`
- `CAPACITY_RESERVATION`
- `POWER_COMMITMENT`
- `MATERIAL_CAPACITY_ADD`
- `SUPPLIER_PURCHASE_COMMITMENT`
- `ACQUISITION`
- `STRATEGIC_INVESTMENT`
- `PATENT_GRANT`
- `PATENT_ASSIGNMENT`
- `PATENT_INVALIDATION`
- `DESIGN_WIN`
- `REGULATORY_APPROVAL`
- `EXPORT_CONTROL`
- `GOVERNMENT_AWARD`
- `HIRING_CLUSTER`
- `SPOT_PRICE_BREAK`
- `INVENTORY_BUILD`
- `ORDER_CANCELLATION`
- `LEAD_TIME_CHANGE`
- `PREDICTION_MARKET_REPRICE`
- `EQUITY_REPRICE`

Every event must answer: **which dependency edge could this change, by how much, and what would falsify that interpretation?**
