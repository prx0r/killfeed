# Source calibration and information lineage

Never permanently hard-code `arxiv=5, github=4, twitter=1`. Learn reliability by topic, author/repository, historical lead time, false-positive rate, Brier/calibration score, independence and market reaction.

Track `origin_claim_id`, `derived_from`, `independence_group`, `first_seen`, `source_timestamp`, `publication_timestamp`, `author/repo/topic`, `historical_accuracy`, `historical_lead_time`.

An echo chain — researcher -> X -> Polymarket -> Reddit -> news -> X — is one information family, not six confirmations.

Prediction-market features: probability, volume, liquidity, spread, price velocity, order-book imbalance, time to resolution.

Equity features: spot, options skew, implied vol, borrow/short-interest where available, valuation duration, revenue purity.

The alpha object is often the **disagreement between clocks**.
