# Starter collectors

Minimal read-only examples that print JSON for piping into an event store.

- `polymarket_gamma.py QUERY`
- `openalex_search.py QUERY`
- `sec_submissions.py CIK`
- `usaspending_search.py KEYWORD`
- `grants_search.py KEYWORD`
- `github_repo_events.py OWNER REPO [GITHUB_TOKEN]`

Respect provider rate limits and terms. Set a descriptive `SEC_USER_AGENT` for SEC requests.
